# 历史归档说明

这里保存过去的设计、实施记录与实验结果。它们用于追溯决策，不作为当前配置、接口或功能承诺。

- `design/`：早期产品方案、统一Agent原案、场景清单与上版说明。部分设想尚未实现。
- `records/`：重构、目录迁移和模型接入时的记录，测试数和模型名对应当时版本。
- `experiments/`：旧样书及验收报告说明；真实输出仍在后端的evaluations/runs，不随文档复制。
- `screenshots/`：旧界面改版截图，不作为当前UI的验收证明。
- `skills-v1/`：旧版写作技能，当前运行不从这里加载。

当前系统的唯一阅读入口是[00-阅读导航](../00-阅读导航.md)。引用历史内容时应写明是原始方案、实测记录还是当前实现，不能把模拟测试计作真实模型作品验收。
