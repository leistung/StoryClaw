# StoryClaw 创作室界面改版

> 历史归档：保留当时方案或验证结果，不代表当前实现。现行说明从[阅读导航](../../00-阅读导航.md)开始；文中旧命令不应直接照做。

参考用户提供的画布平台截图，采用固定侧栏、大尺寸灵感入口、卡片分区的结构；内容与操作围绕长篇小说创作组织。未使用参考平台的品牌、图片或其他素材。

视觉：暖黑背景、鼠尾草绿主色、细边框、低对比点阵、宋体正文与原创山形书封。保留浅色主题和主题选择记忆，新用户默认深色。品牌样式集中在 frontend/src/styles/studio.css，基础主题变量在 index.css。

## 页面与交互

- 首页：问候、灵感输入、类型选择、预设灵感、真实字数统计、作品进度、创作工具入口。
- 我的作品：类型筛选、标题搜索、卡片/列表切换、加载骨架、空状态与失败重试。
- 新建作品：首页灵感及类型带入既有创建表单，创建后在当前页进入作品，避免异步新窗口被浏览器拦截。
- 写作工作台：目录、稿纸与创作伙伴三栏；可拖动宽度、切换专注模式、导出Markdown、查看保存状态。
- 快捷工具：直接进入最近作品的大纲、角色或创作页面；没有作品时引导新建。AI建议先填入输入框，由用户发送，不自动消耗积分。
- 章节打开：默认最后一个已有正文的章节；纯文本生成稿保留自然段，已保存富文本保留格式，切换后回到正文开头。加载本身不主动保存正文。
- 手机：侧栏抽屉、可滚动标签、章节选择框；工作台默认专注布局，可展开目录与助手。
- 登录/注册：沿用已有认证流程，统一为创作室视觉。

## 大纲任务与创作门槛（2026-10-25）

- 顶部说明可关闭，浏览器记住隐藏状态；帮助入口仍在创作路线。
- 大纲生成使用持久化 WorkJob，前端轮询，切换标签、刷新、关闭页面不会取消。任务详情提供结果入口，失败保留原因。服务重启中断不会自动重复调用模型。
- 同一书籍最多一个排队或运行任务，完成或取消后再推进；不同作品仍受用户三个待执行任务总量限制。当前默认单消费者按创建时间执行，不承诺固定排队时长。
- 角色和世界观可先手工整理，角色分析为建议报告。大纲保存后需人工确认，确认绑定规范化内容哈希；重新保存或生成会重置确认。旧作品也需首次确认，已有正文不删除。
- 情节分析、章节场景任务单、AI 正文和批量写作均要求确认大纲；手写编辑不要求。任务入队记录大纲快照摘要，执行前再校验。场景任务单为可选细化步骤，避免把所有用户强制绑在复杂流程里。
- 未保存的大纲编辑在当前浏览器标签页 sessionStorage 暂存（按用户和作品隔离），可保存或放弃本地修改，不覆盖服务器新结果。
- 测试覆盖未确认拦截、跨用户确认拒绝、过期版本确认、保存清除确认、重复任务去重、执行中禁止改纲、后台完成恢复，结合原有正文版本/积分/并发防覆盖回归。

开书时移除旧的自动大纲/情节/角色复选框，避免绕过人工确认、启动未跟踪的异步链。旧客户端提交自动生成标记会收到明确的 400 提示，不会先创建作品再失败。novel-lab 等脚本在保存大纲后，也需作者在工作台确认当前版本再发起写作。
