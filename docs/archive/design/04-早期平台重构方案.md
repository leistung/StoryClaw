# StoryClaw 平台重构进度

> 历史归档：保留当时方案或验证结果，不代表当前实现。现行说明从[阅读导航](../../00-阅读导航.md)开始；文中旧命令不应直接照做。

目标：面向用户运营，统一注册登录、平台模型和积分；保留社区、会员与计费。
技术：React + FastAPI + LangChain / LangGraph。

## 本批已实现

- 注册后再登录，无本地版选择；旧账号启动时归一到平台版本，保留账号、作品与历史个人配置记录。
- 原个人模型配置 API 停止挂载，旧前端地址跳转中台。普通用户不配置密钥。
- 独立 `admin-frontend/` React 中台，独立 Docker 服务与管理员登录，默认端口 5174。创作站不再打包中台实现。
- 移除未使用的 Redis 和可选 Nginx，保留 Milvus 所需 etcd / MinIO。
- 运营中台：统计、用户分页、用户作品与积分流水、带原因和幂等编号的积分调整、平台模型与向量模型、定价、会员套餐、请求元数据及操作审计。
- 管理配置存 PostgreSQL；YAML 只作为初始配置，不再写只读挂载。
- 模型密钥加密保存，API 不返回密钥或密文；模型可配置上游名称及独立端点。
- `/auth/me` 返回管理员标识；中台前端和后端均校验角色，角色只能由服务端操作设置。
- 注册登录、侧边导航、作品页横幅和工作区设置调整；移除演示账号。
- 管理员积分调整采用行锁和幂等编号，现有 AI 积分扣减改为原子 SQL，避免覆盖其他余额修改。
- 默认禁用模拟支付，页面显示支付未开放；不将模拟购买当作真实会员订单。
- Embedding 返回数量、顺序、维度和有限数值校验；章节修改后索引状态设为 pending；章节关系重建清理旧关系并使用事务。
- 默认不允许入库回退内存；内存索引不标记为持久入库成功。
- 数据库增量迁移 `0008_platform`，新表 platform_configs / platform_events。

## 数据架构决定

保留 PostgreSQL、Milvus、Neo4j，不采用上一版建议的 pgvector 替代路线。
详见 [小说上下文与三库设计](09-上版知识库设计.md)。图片文件存对象存储或持久文件卷，PostgreSQL 存元数据和存储键。

## 继续实施的工作

1. 章节版本、索引任务及原文哈希清单，过滤过期索引；草稿和正式正文区分。
2. 持久生成任务、worker、SSE 事件重放、断点连接池、任务级结算及预算冻结；目前请求驱动生成仍保留。

4. 定价和会员由 JSON 编辑器升级为完整表单；会员到期权益、订单、支付渠道、回调、退款和对账闭环。
5. 请求日志异常捕获、保留期清理、查询筛选及导出；当前日志仅含请求元数据与管理审计，不是全部运行日志。

7. 工作区进一步拆分模块，并逐页完成社区、阅读、消息与充值页的视觉重设计。本批未宣称所有页面已重做。
8. 生产关闭 create_all，完成已有 Demo 数据库的 Alembic 基线核对和升级演练；目前保持 Demo 启动自动建表。
