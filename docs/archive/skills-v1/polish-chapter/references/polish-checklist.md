# 文笔润色检查清单

## 润色目标类型

| 目标 | 适用场景 | 侧重点 |
|------|---------|--------|
| 提升文笔 | 通用润色 | 用词精准度、意象新颖度、节奏感 |
| 增强画面感 | 场景描写薄弱 | 五感调动、空间层次、光影色彩 |
| 强化情感 | 情绪表达平淡 | 心理层次、潜台词、身体反应 |
| 节奏调整 | 句式单一/拖沓 | 长短句交替、留白、断句节奏 |
| 对话打磨 | 角色口吻模糊 | 个性化语言、潜台词、信息差 |

## 润色原则

1. **保留原意**：不改变情节走向、人物关系、核心信息
2. **最小改动**：能不改则不改，避免为润色而润色导致风格失真
3. **风格统一**：润色后片段需与上下文文风一致，不突兀
4. **长度控制**：润色版字数与原文偏差不超过 30%

## 检查维度

### 用词层
- 动词是否精准（避免泛动词）
- 形容词是否新颖（避免套话）
- 是否有冗余修饰词

### 句式层
- 是否有长短句交替
- 是否有意识流或蒙太奇节奏
- 排比对仗是否自然不造作

### 意象层
- 是否有具象化的感官细节
- 比喻是否新颖且贴切
- 是否有留白与潜台词

### 情感层
- 情绪是否通过动作环境间接传达
- 是否避免直接点破
- 情感递进是否有层次

## 输出要求

- 直接输出润色后的文本，不带说明性元话语
- 保持原文的段落结构
- 不添加 Markdown 格式标记
- 润色片段应能直接替换原 selected_text
