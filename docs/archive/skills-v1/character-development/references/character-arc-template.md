# 角色弧光报告模板

## 报告结构（Markdown 输出）

```
# {角色名}·成长弧光报告

## 起始状态
- 性格：核心性格特征 3-5 条
- 信念：角色信奉的观念（将被弧光打破或强化）
- 能力：长板与短板
- 关系：与关键人物的初始状态

## 阶段一：{阶段名}（第X-Y章）
- 触发事件：导致转变的具体事件
- 内在转变：心理层面的微调
- 外在行为：转变后的行为表现
- 关键对白示例：符合角色口吻的台词

## 阶段二：...（重复）

## 与主线呼应点
- 主线节点A → 角色反应
- 主线节点B → 角色转变

## 潜在偏离风险
- 风险1：某情境下可能崩人设的防范
- 风险2：...
```

## 弧光设计原则

1. **内在逻辑**：性格转变必须有因果链，不能突兀
2. **渐进式**：每个阶段只转变一个维度，避免一次到位
3. **与主线呼应**：弧光节点需对应主线情节节点
4. **对白一致性**：示例台词需符合角色口吻与教育背景

## 弧光类型参考

| 类型 | 轨迹 | 适用角色 |
|------|------|---------|
| 成长型 | 懦弱→勇敢→担当 | 主角 |
| 堕落型 | 善良→犹疑→黑化 | 反派/灰色角色 |
| 循环型 | A→B→回归A（认知升级） | 配角 |
| 静态型 | 始终如一（锚点作用） | 导师/挚友 |

## 人设偏离检查

- 转变前是否有足够铺垫事件
- 转变后是否与前文性格有断裂
- 对白口吻是否与角色身份匹配
- 是否有"工具人"倾向（只为推动情节而转变）
