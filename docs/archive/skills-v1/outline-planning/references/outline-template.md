# 大纲规划模板与规范

## 输出 JSON 结构

```json
{
  "volumes": [
    {
      "name": "第1卷 卷名",
      "chapters": [
        {
          "number": 1,
          "title": "章节标题",
          "summary": "50字内梗概，包含本章核心冲突与推进点"
        }
      ]
    }
  ]
}
```

## 分卷规则

- 每 5-10 章一卷，卷名需体现该卷主题弧（如"初遇篇""离散篇""重逢篇"）
- 卷与卷之间应有明确的情感/情节转折点
- 首卷需在前 3 章完成主角出场、核心矛盾铺设、关键配角引入

## 章节梗概要求

- 字数：30-50 字，不超过 80 字
- 内容：包含本章的冲突点、推进方向、关键事件
- 避免：只写环境描写或纯过渡章，每章必须有情节增量
- 格式：陈述句，不带问句或感叹号

## 类型惯例参考

| 类型 | 开篇节奏 | 中段重点 | 收束方式 |
|------|---------|---------|---------|
| 都市言情 | 快速相遇+误会 | 情感拉扯+身份揭示 | 双向奔赴或虐恋收尾 |
| 玄幻升级 | 金手指激活 | 境界突破+势力冲突 | 大比/夺宝结束一卷 |
| 悬疑推理 | 案件引入 | 线索铺设+反转 | 真相揭露+伏笔延伸 |
| 古言宅斗 | 入府/嫁入 | 妻妾/婆媳博弈 | 夺权/洗冤 |

## 常见问题

| 问题 | 修复建议 |
|------|---------|
| 章节数不等于 target_chapters | 检查大纲生成的循环逻辑 |
| 卷名千篇一律 | 注入书籍类型与主角设定作为参考 |
| 梗概过于笼统 | 要求包含具体冲突点而非模糊描述 |
| 章节标题与类型不符 | 在 prompt 中强调类型惯例 |
