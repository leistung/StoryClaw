# 段内续写技巧参考

## 续写原则

1. **衔接无缝**：续写片段必须紧接 `prefix_text` 末尾，不重复前文，不添加标题或空行
2. **风格一致**：人称、时态、语气、节奏需与前文保持统一
3. **情节推进**：续写内容需有信息增量，避免原地打转的描写堆砌
4. **长度控制**：续写片段建议 300-800 字，过长会偏离原文节奏

## 续写模式

### 场景延展
当前文停留在环境描写时，续写应补充感官细节（视觉/听觉/触觉），逐步引入人物动作。

### 对话延续
当前文是对话片段时，续写应继续角色的对白或反应，注意保持角色口吻与性格一致。

### 情感深化
当前文进入心理描写时，续写应递进情感层次，避免直接点破，用意象和动作暗示。

### 动作推进
当前文在事件节点时，续写应推进动作序列，保持节奏感，适时留白。

## 常见问题

| 问题 | 示例 | 修复 |
|------|------|------|
| 重复前文 | prefix 末尾是"她转身"，续写又写"她转身" | 续写应从"转身"之后开始 |
| 风格断裂 | 前文第三人称，续写变成第一人称 | 检测 prefix 的 POV 并保持 |
| 信息冗余 | 续写重复解释已知设定 | 删除背景铺垫，直接推进情节 |
| 节奏失控 | 续写全是长句描写无断句 | 用短句调节奏，模仿前文句式 |

## 输出要求

- 直接输出续写正文，不带"以下是续写内容"等元话语
- 不添加 Markdown 格式或代码块标记
- 续写片段应能直接拼接到 `prefix_text` 末尾
