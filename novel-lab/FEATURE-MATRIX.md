# 核心功能与验收证据

“已覆盖”表示测试代码包含该路径；实际成功与否以 runs 下回执和 report 为准。此文不是运行通过报告。

| 功能 | 后端/存储 | 测试方法 |
|---|---|---|
| 登录、作品归属 | auth、books | 现有用户登录并验证实例所有者 |
| 书籍元信息、卷章结构 | books、chapters | 创建、读取、更新与顺序校验 |
| 人物、场景、物件、剧情规则 | config | 写入初始设定，读取与维护台账 |
| 全书大纲 | outline generate/read/update | 真实模型调用，连续40章，无占位 |
| 当前章场景任务单 | chapter plan（本次新增） | 3–5场景结构校验并保存 |
| 正文生成 | generate、generate-stream、multi-write | 覆盖三类调用，再读回正文 |
| 润色、续写 | polish、continue | 返回非空结果；不覆盖已验收正文 |
| 标题、灵感、场景、对白 | assist | 独立样例真实调用 |
| 摘要、人物、情节、一致性 | analyze | 保存报告，滚动台账，每5章检查 |
| 向量入库和检索 | ingest、rag/query、Milvus | 每章入库后查询，不只看HTTP200 |
| 图实体 | Neo4j、rag-status | 整本验收检查实际实体记录 |
| 阅读配置、只读分享 | reading-configs、messages/share | 创建配置，分享内容回读比对 |
| 整本导出 | books/export（本次新增） | 四十章正文逐章包含校验 |
| 断点恢复 | 客户端state与锁 | 已验收哈希保护、避免整批重跑 |
| 生产任务队列 | 尚未实现 | 设计建议，不能宣称可用 |
| 结构化时间事实和伏笔闭环 | 部分：文本台账与模型分析 | 尚无严格自动语义验收 |
| 出版级自动修订 | 尚未实现 | 人工审稿后定向修改 |

不将注册、支付、会员、社区、运营中台所有业务都混入长篇写作压力测试；它们需要独立权限、幂等性与财务测试。也不在现有账号下执行删除作品或清空数据库测试。
