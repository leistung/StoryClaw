# 前情提要格式规范

## 输出 JSON 结构

```json
{
  "main_line": "主线推进描述（30-100字）",
  "characters": [
    {"name": "角色名", "state": "当前状态（性格/处境/关系变化）"}
  ],
  "events": [
    {"chapter": 1, "event": "关键事件简述（20-50字）"}
  ],
  "foreshadowing": [
    {"id": "f1", "status": "planted|resolved", "description": "伏笔内容"}
  ]
}
```

## 字段要求

### main_line（主线推进）
- 字数：30-100 字
- 内容：概括指定章节范围内主线如何推进
- 要求：体现因果关系，非流水账
- 避免：剧透未发生的伏笔回收

### characters（人物状态）
- 只列出有变化的角色，不变的不列
- state 字段：当前性格/处境/关系状态
- 避免剧透：不透露角色尚未做出的决定

### events（关键事件）
- 每章只列 1-2 个关键事件
- 字数：20-50 字/事件
- 格式：主谓宾完整陈述句
- 避免：罗列所有情节，只取推动主线的关键点

### foreshadowing（伏笔状态）
- 只列指定范围内已埋或已回收的伏笔
- status：planted（已埋未收）/ resolved（已回收）
- 不剧透未发生的回收

## 使用场景

| 场景 | 章节范围 | 侧重点 |
|------|---------|--------|
| 续写前回顾 | 已写全部章 | 人物状态+伏笔 |
| 读者跳章 | 跳过的章号 | 主线+关键事件 |
| 大纲校准 | 已写章号 | 主线推进+伏笔 |
| 一致性审查前置 | 待审章号前 | 全字段 |
