# 按用途组织摘要

内容组织服从调用方格式。本工作单帮助取舍，不要求返回固定 JSON 字段或每章固定事件数。

## 给读者的前情提要

写到当前阅读点，说明主角处境、关键关系和必须理解的事件后果。删除对后文无作用的赶路与重复争执。避免从作者视角提前解释凶手身份、隐情或将来结局；读者已知而角色未知的信息，仅在允许的剧透范围内保留。

## 给写作者的阶段记忆

保留目标如何推进、关键选择与代价、当前物品资源、人物信息边界、仍生效承诺、已埋未解问题。区分当前状态和历史变化：曾经受伤不等于此刻仍无法行走；原文未说明恢复时则保留不确定性。

## 给审稿者的证据摘要

围绕本次疑点选择双端来源、时间锚点、人物说法与反证。不要只给流畅故事概述，因为审稿者需要知道哪句话支持哪项判断。标明缺章、版本不匹配和证据范围。

## 长范围合并

先按章提炼有来源的增量，再按人物、事件与情节线合并。用最新有效变化更新当前状态，同时保留仍影响后文的历史原因。远期内容可以保留卷级概览与定位指针，但不能让关键承诺在多轮压缩后消失。

## 最后检查

摘要中每个新事实是否有原文；计划是否被误写成完成；角色说法是否变成客观真相；重要限定词是否丢失；人物、物品是否因省略交接而瞬移；有没有因为删去失败过程，让后续决定看起来毫无理由。
