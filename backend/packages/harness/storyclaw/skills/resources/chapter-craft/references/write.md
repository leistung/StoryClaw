# 从章纲写到具体场景

## 开场接住什么

先辨认前章最后一个动作、问题或决定的结果。前章结束于主角已经签下借条，新章可以写借条带来的期限、对方的新条件和主角下一步安排，不能再次用“他终于决定要不要借钱”重开同一抉择。

## 场景内部的推进

确定此刻谁想让谁改变行为。主角提出办法，对方因自己的利益接受、拒绝或增加条件；新动作揭示信息，人物据此选择。动作、对白和内心反应互相影响，不是先写一段景物、再一段设定、再大段情绪的固定组合。

## 把抽象句变成可读事件

薄弱：“他展现出聪明才智，很快赢得众人信任。”

可操作的写法：他没有要求店员相信自己，先把两张收据按时间排好，请店员核对交班记录。店员仍不肯交出原件，却答应让他在柜台内当面拍照。信任只增加到允许核对的程度；人物能力通过选取证据与谈条件表现。

示例只演示表现方式，使用时必须替换为本书已有事实，不能把收据和店员带进无关作品。

## 篇幅如何分配

重要的谈判、关系决定、证据确认和后果值得展开；重复的赶路、已讲清的背景可以压缩。需要扩写时补充双方策略与反应，检查新增内容是否改变选择；需要缩写时保留动机、关键动作和结果，避免只留下人物突然改变主意。

## 结束时的状态差

人物得到、失去、理解、承诺或暴露了什么？读者为何愿意继续？结果可以是小胜、失败、暂时和解、犹豫或平静后的决定，不必每次危险升级。保留作者指定的开放感，不擅自写全书完结。

## 正文清洁检查

删除生成说明、分析标签、无来源的“果然”、替读者总结人生的旁白以及不服务视角的夸张评价。不要用禁词表机械替换“仿佛”“忽然”；判断它在当前句子里是否有准确作用。
