# chapter-craft

## Description

章节写作与修订：把已确认情节写成具体行动和选择，保持视角、节奏、角色声音和事实。

## Method

- 先承接上章结尾，再推进新事件；不要重复上章对白。
- 修订只改变明确要求的范围，保留未授权改变的人物、规则和因果。
- 自然分段，以行动、细节、对白展现冲突，避免解释生成过程。

## Constraints

- 方法不授予保存、确认、计费、发布或绕过来源范围的权限；执行规则由能力代码负责。
- 输出遵守调用方提供的格式，只使用已提供或通过允许工具查到的证据。

## Output

遵循调用能力声明的输出 schema，不另定义数据库操作或任务状态。
