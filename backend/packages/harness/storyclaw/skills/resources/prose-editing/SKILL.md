# prose-editing

## Description

对绑定选区进行润色、扩缩写，或在指定光标位置续写新片段；保留上下文、人物声音与事实，只交付可替换或插入的候选正文。

## Parameters

读取任务模式、选区或光标引用、完整可用本章、光标前后文本、作者修改目标和篇幅约束。选区、前缀和后缀是不同对象；先确认候选要替换哪里或插到哪里。

## Method

1. 做边界判断：润色修改选区，续写只生成插入片段。读取本章是为了理解上下文，不等于获得整章重写授权；有后缀时必须同时检查前接与后接。
2. 提取语义保留项：人物、指代、事件、否定、数字、时间、说话者、知情程度、关键动作顺序和关系。作者明确要改变其中一项时，以其要求为准并核对直接后果。
3. 识别原文声音：叙述人称、视角距离、语汇、句式、对话方式与情绪强度。跟随当前作品，不默认把口语改书面、把简洁改华丽、把有意重复全部删掉。
4. 润色先解决含混、错位指代、无效重复、视角漂移和动作衔接，再调整准确动词、节奏与细节。让修改服务作者指定目标，不为了显示改过而替换所有句子。
5. 扩写增加读者理解选择所必需的行动、反应、细节或潜台词；缩写合并重复信息，保留动因和结果。不要用新增角色、重大事件或新设定填长度。
6. 续写先判断光标处未完成的动作或问答，从该点推进。章中插入要接回原后缀，不提前拿走后缀要用的物品、改变出场顺序或把后缀要说的信息重复一遍；章末续写也不默认另开下一章。
7. 情绪通过符合视角的动作、停顿、感官与选择表达，保留原文需要的直接陈述。不要机械删除所有抽象词或套统一禁词表，避免让人物声音趋同。
8. 把候选与前后句在心中拼接，检查语法、代词、动作、信息、段落和篇幅。只交付候选本体，原文大段前缀、后缀不再重复输出。

## Constraints

- 绑定位置由系统校验，不能自行伪造范围、版本哈希或采用结果；生成候选不等于已经修改正文。
- 作者没有要求时不增加人物关系、历史秘密、数值变化或新能力；未知信息不写成确定结论。
- 长度以本次参数为准，不把示例中的字数或“偏差不超过某百分比”当通用硬限制。
- 只输出调用方要求的候选，不附润色理由、标题、引号包装、自检清单或代码块。
- 此 Skill 提供创作方法；保存、采用、计费、发布和数据访问权限由调用能力决定。输出服从调用方 schema，不把方法示例变成新接口。

## Output

可直接替换选区或插入光标的正文，保留有意义的段落。续写只包含新内容；润色不带未选中上下文。调用方使用 JSON 包装时仅在正文对应字段写候选。
