# 按修改目标核对

只选择当前目标相关的检查，不要求每次改掉所有维度。

| 作者目标 | 优先处理 | 需要保留 |
| --- | --- | --- |
| 更清楚 | 指代、主语、动作顺序、歧义 | 原有事件与立场 |
| 更紧凑 | 重复说明、绕句、无作用回顾 | 动机、选择与结果 |
| 更有画面 | 视角内可观察的动作和空间 | 原物品、位置和证据 |
| 更有情绪 | 停顿、反应、回避与选择 | 情绪强度和心理确定程度 |
| 更自然 | 角色语汇、叙述距离、对白回应 | 作者原有声音 |
| 更克制 | 过度解释、连续比喻、重复总结 | 必要说明与有意修辞 |

## 语义对照

改前改后分别核对人物、说话者、否定、数量、时间、关系、信息来源和动作结果。它们发生变化时，应能回到作者的明确要求；不能用“润色需要”解释事实变化。

## 避免机械处理

长短句不必交替出现，段落不必等长，直接写“他怕了”不必一律改成肢体描写。词频只能提醒检查，不能证明某个词必须删。保留人物有意的口吃、重复和停顿；删的是无作用重复，不是角色特征。

## 替换检验

把候选放回两端边界，看代词是否明确、标点是否相接、对白引号是否配对、后续动作是否还有原因。对半句选区尤其检查是否多补一个主语或重复句末。最后只交付候选，不把清单附进正文。
