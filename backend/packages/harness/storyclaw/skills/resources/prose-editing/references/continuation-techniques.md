# 不同断点的续写判断

## 对话断点

确认谁刚提出什么要求、对方知道什么、为什么不能直接同意。下一句可以回答、回避、提条件或做动作，但要与前一句有关系。不要让新人物不经引入突然加入对话，也不要让角色说出尚未知晓的秘密。

## 动作断点

保持动作的空间和持有关系。人物伸手取物后可以拿到、落空、被制止或改变主意；需要有可见原因。不要跳过尚未完成的关键动作，直接宣布关系或战局已经改变。

## 观察与心理断点

观察引出的是视角人物能作出的判断，不是作者全知解答。心理可以改变下一步选择，避免重复一段抽象自我分析后人物仍停在原地。场景安静也可以通过一个决定推进，不必突然制造袭击。

## 场景交界

只有作者要求或既有结构支持时才换时空。交界说明必要的时间与位置变化，不重新介绍读者已认识的人物。章中有后缀时，新增内容必须能回到后缀，不为展示续写能力另开支线。

## 增量检查

新增片段带来了什么行动、信息、决定或关系变化？重复的环境与情绪是否可以删除？既有承诺有没有被遗忘？人物为什么会作出这一步？无法用当前资料回答时，收窄推进而不是发明重大前史。
