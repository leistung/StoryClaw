# idea-generation

## Description

围绕作者题材、受众体验和限制发散可比较的故事创意、困局与发展方向，提供有具体矛盾和代价的候选，不将候选写成已采用事实。

## Parameters

读取作者的原始想法、题材与情绪偏好、已有世界和角色、禁用内容、候选数量及本次规模。分清从零开书、既有作品找方向和局部解决情节问题。

## Method

1. 把输入拆成必须保留的限制、可变化的维度和真正未决定的问题。作者已经明确的内容不反复询问；影响方向的空缺用少量问题或明确假设处理。
2. 找故事发动机：具体人物在当前处境下必须做什么，谁或什么阻挡，失败损失什么，成功又会带来什么新难题。仅有新奇职业、金手指或世界标签不等于故事。
3. 选择不同发散轴：主角处境、对手动机、资源规则、关系结构、信息差或选择代价。候选应在至少一个核心机制上有实质区别，不只是改姓名、时代和地点。
4. 给每个方向一个可展开的入口：触发事件、第一步行动、初期阻碍和阶段变化，并说明为何可以持续写或适合短篇。不要未经要求预写几百章、完整人物表和全套设定。
5. 既有小说先保持正史。新方向必须从当前结果和未解问题生长，不能靠人物遗忘、能力突变或重演上章来重启故事。
6. 让人物保有主动选择与代价；对手有合理利益，冲突可持续。对偶然、误会和秘密的使用检查是否只在替作者强行制造问题。
7. 以作者偏好比较候选：哪种更重关系、哪种更依赖调查、哪种需要较多背景准备，指出创作风险与未决条件。推荐理由来自当前任务，不宣称市场一定接受。
8. 收敛时保留作者喜欢的核心，修改其明确不喜欢的机制。不要每次反馈后把所有已确认选择重新打散；采用与实际执行仍由对应能力处理。

## Constraints

- 未核实的市场、平台和读者趋势只能作为假设；不凭空承诺热度、收入或平台适配。
- 参考作品只提炼高层机制，不按其角色关系与事件次序逐章换词改写。
- 已有作品的候选不直接变成新事实；解释怎样接入，必要的改稿依赖要明示。
- 数量与展开深度由作者要求决定，不固定永远给三个点子，也不交付只有一句口号的方向。
- 此 Skill 提供创作方法；保存、采用、计费、发布和数据访问权限由调用能力决定。输出服从调用方 schema，不把方法示例变成新接口。

## Output

给能横向比较的候选：一句核心矛盾、人物行动、关键代价、可展开方向和待确认点。返回格式遵循调用方；不在纯候选生成中声称已经建书、更新大纲或开始任务。
