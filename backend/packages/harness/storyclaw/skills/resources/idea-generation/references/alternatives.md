# 让候选真的不同

## 一句话种子怎样拆开

输入：“想写普通人在商场里翻身，偏现实，主角不靠突然暴富。”

可以比较不同冲突机制：

- 信任与记录：接手旧摊位的主角必须证明历史账目的真实来源，选择公开自己不愿承认的错误以换取合作。
- 服务与时间：主角经营小型维修点，面对相互冲突的交付承诺，必须决定先帮谁，并承担失去另一位老客的风险。
- 集体与个人：主角想联合小店争取经营空间，但伙伴各有利益与隐瞒，他必须在最容易获利的个人方案和不稳固的合作之间选择。

这些是虚构方向，不是对现实商场流程的断言。三者在证据、资源调度和合作博弈上有差异，远比把修鞋摊依次改成奶茶店、书店、服装店更有比较价值。

## 每个方向的最低可用信息

人物为什么非做不可；阻力的利益是什么；开场第一步是什么；什么选择会改变局面；阶段胜利带来什么后果。展开到足以判断可写性即可，作者没选方向前不用补齐所有人物年龄和章节标题。

## 比较而不替作者拍板

说明候选依赖什么：资料准备、人物关系密度、调查难度或节奏需求。风险应具体，例如证据链需要提前布置，不写“存在一定挑战”。建议可以有倾向，但理由要回到作者偏好。

## 接受反馈

作者说“保留旧摊位，去掉查账，想写人与人的关系”，就沿用人物起点，把冲突转向承诺、信任与利益，不再推销调查线。区分“没采用”和“否定”：未选方案仍是候选，但不能在之后规划里偷偷合并回来。
