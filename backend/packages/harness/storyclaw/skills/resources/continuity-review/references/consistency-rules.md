# 一致性审查工作单

## 定向检查

| 维度 | 要核对的状态 | 容易误判的情况 |
| --- | --- | --- |
| 身份与关系 | 姓名、别名、亲属、立场、生死 | 别名、伪装、角色误认 |
| 时间与地点 | 先后、跨度、移动、季节 | 回忆、并行线、未给精确时间 |
| 物品与资源 | 持有、交接、消耗、恢复 | 借用、补给、后来归还 |
| 能力与规则 | 使用条件、代价、反制 | 早已解释的例外 |
| 知情与信念 | 获知路径、范围与可信程度 | 猜测、谎言、传闻 |
| 事件与承诺 | 已完成结果、债务、约定 | 有新条件的再次谈判 |
| 伏笔与结构 | 铺垫、期限、兑现证据 | 尚未到阶段、作者允许暂缓 |

## 一条问题怎样写

说明审查对象；引用当前片段和相关历史来源；解释冲突成立所需的条件；区分已经证实、值得核对或只是表达建议；说明读者理解和后续因果受什么影响；给出最小修复及其代价。引用来源以真实输入为准。

示例：本章写甲“从内袋取出钥匙”；前章来源片段写甲将唯一钥匙交给乙，当前资料未见归还。若两章间交接记录完整，可提示持有冲突；若中间缺章，写待核对归还途径，不肯定钥匙绝不可能回到甲手中。

## 严重程度与类别分开

确定矛盾还要看影响范围；拼写差异可能只是别名，也可能导致实体混淆。节奏慢、意象重复、读者期待不明等属于质量建议，不能直接判为正史错误。没有事实与来源支持时，不给出虚假的全书通过率或一致性分数。

## 修订复核

重查被改事实及直接依赖：前句后句、相关物品、角色知识和后续提及。作者只授权调语气时，不建议顺带改事实。不能证明缺陷存在的观察可撤回；不要求为了维持第一次结论而新增证据。
