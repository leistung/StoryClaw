# 区分回顾、呼应与重演

## 比较的是事件状态

把两段事件都简记为“主体—对象—目标—行动—结果—知情变化”。主体和词语相同但目标、代价不同，可以是新的事件；换了用词却再次把同一件已完成的事当首次完成，可能是重演。

- 回顾：一句说明上章已还款，解释此刻为何敢面对债主。
- 后果：还款后发现收据有误，主角争取更正。
- 呼应：主角再次来到第一次交易的摊位，但关系与诉求已经改变。
- 重演：没有新债务或特殊结构的依据，又写他筹集同一笔款、首次还清同一债务，并让人物忘记上次结果。

## 正确识别“第一次”

留意第一次相遇、第一次听说、终于拿到、这才知道、再次确认等词。它们要和人物的经历匹配。可能是不同角色第一次获知，也可能是复核；先检查主语与时间，不能仅搜索“第一次”就报错。

## 对白和动作

重复长对白通常值得核对，但誓言、仪式、刻意回声可以服务结构。指出重复内容和其本应造成的状态变化，再判断是否缺乏新作用。动作描写重复也可能只是风格问题，不能提升为剧情硬冲突。

## 修复层次

若事件已完成，优先从结果之后继续；若是必要复核，明确为何怀疑旧结果及本次新增条件；若是有意重演，提供使读者辨认结构的语境。不要为解决重复凭空创造新债务、新物品或一个从未出现的失忆设定。
