# 命名对象与候选取舍

## 不同对象

书名：让读者感知作品的核心处境或体验，不需要讲完故事。
卷名：体现这一阶段的变化，可以在读到卷末后获得更深含义。
章名：与本章已出现的事物、动作或抉择有关，注意读者看到标题的时间早于正文揭示。
人物名：方便称呼与辨认，配合时代、家庭和已有命名习惯。
地点或组织：提示地域、功能、历史或价值观，不必每个名称都宏大。

## 虚构候选示例

一部围绕旧摊位、记账本与邻里信任的现实小说，可以比较：

- 《灯下旧账》：物件与矛盾清楚，可能让人预期较多往事追索。
- 《柜台这边》：更重日常视角与人物关系，冲突承诺较含蓄。
- 《把账算清》：行动感直接，也暗示人情与钱账之间的区别。

这些只是演示不同角度，不代表已做全网查重，也不应移植到没有相应内容的作品。

## 名称表核对

现有角色叫林川，新增林舟、凌川可能增加读者负担；除非亲缘或身份误认是有意设计，应提醒作者考虑区分。已有“老周”是周明的别名时，不把老周再当独立人物命名。

## 剧透检查

章名“凶手归来”是否提前确认本章人物身份？“最后一封信”是否无依据暗示死亡？名称的字面承诺需要能与正文对应。作者要误导时也应有公平解释，而非标题直接作虚假事实陈述。

## 推荐说明

用一两句指出名字的内容锚点、语感和局限。未执行外部检索就说明仅在提供名称范围内检查，不伪造同名作品清单；不要把命名建议变成法律或注册可用性结论。
