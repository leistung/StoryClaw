# 让设定实际约束故事

## 一条规则的工作单

说明“谁，在什么条件下，能做什么，需付出什么，失败会怎样，别人如何察觉，有哪些有依据的例外”。不必每次使用表格，但不能只有“能力强大、代价很高”这种空话。

虚构例：修补记忆的术式需要物主亲手保留的物件，只能恢复与该物件有关的一段感官印象；物件在使用后失去相关痕迹。别人可以核对恢复过程，却不能由此证明记忆中的人物判断为真。它能找线索，但不能无成本回答一切，也保留了“亲见”与“解释”的区别。

## 现实场景也需要规则

设计商场、学校、工厂或社区时，先问准入、分工、资源与冲突处理。谁负责钥匙，谁记录交接，公开信息在哪里，熟人关系能改变什么、不能改变什么。作者未指定现实机构时可用虚构组织；不得将自行设计的流程写成真实法规或行业通则。

## 组织差异

比较组织的生存目标、资源来源、内部决策、对外承诺与不愿公开的矛盾。两家机构都“实力雄厚、神秘强大”不能形成冲突；一家依赖长期信誉、另一家依赖短期周转，才会对同一问题采取不同策略。

## 空间可用性

视角人物进来能看到哪里，声音能传到哪里，移动需要经过谁，有无障碍和时间消耗。增加光线、天气或建筑细节前，检查是否改变了可见性、听觉、逃离路径或情绪判断。若改变会影响前文证据，标为情节修改而非装饰润色。

## 压测问题

主角能否重复使用同一办法逃避所有代价？对手为什么不用相同办法？普通人如何在该规则下生活？例外是否有先前依据？新规则是否反过来使早期人物行为失去意义？发现此类问题先给最小补充或未来调整方案，不擅自重写既有正文。
