# 连载的阶段设计与调整

## 从已发生的结果继续

先整理当前局面：主角拿到了什么、失去了什么、欠了谁的承诺、对手已采取什么行动。下一阶段必须从这个结果出发。若前卷已经查清盗窃者，新卷可以追查收货渠道、面对追责或选择是否公开证据，不能重新以“不知窃贼是谁”开场。

## 每个阶段的工作单

- 入口：人物处境、可用资源、关系与未解问题。
- 目标：读者能判断是否推进的具体目标，如争取展位、修复关键关系、查清账本来源。
- 阻力：谁有利益不让目标实现，具体拥有什么筹码。
- 升级：主角的第一种策略为什么不够，失败留下什么后果。
- 选择：为了改变局面，主角放弃什么或者承担什么风险。
- 结算：本阶段确实解决了什么；留下的后果怎样打开下一阶段。

阶段可以包含调查、关系重建、经营、休整，不要求每卷都有大敌或生死决战。休整也应改变资源安排、人物判断或未来选择。

## 近期具体，远期有条件

近期写可行动的事件链；中期写冲突和关系转变的条件；远期写候选收束与尚未满足的前置条件。预估一千章不等于逐章排满，也不等于每隔固定章数升一级。作者要求定长完整大纲时，改用有限范围内的铺垫—发展—兑现检查。

## 多线如何汇合

给每条支线一个独立目标，再说明它怎样改变主线的资源、认知或关系。若删掉一条支线对任何人的选择都无影响，优先缩短、合并或暂缓，而不是加更多支线填空。

## 调整后续时

保留已发生事件、作者确认设定及其来源。列出受影响的未来计划、未兑现承诺和章纲。允许作者改方向；需要改前文才能成立的方案应明确提出改稿依赖，不能在新大纲里偷偷完成回溯修改。
