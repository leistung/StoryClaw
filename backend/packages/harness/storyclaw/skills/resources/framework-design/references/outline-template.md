# 总纲与分卷的展开工作单

这是内容工作单，不是新的 JSON schema。调用方只有 overview 和卷 goal 时，把相应信息组织进这些字段，不擅自增加数据库字段。

## 总纲要回答的问题

作品从哪种具体失衡开始；主角为什么不能继续原来的生活；主角与对手各自争什么；主要关系怎样逼迫选择；规则怎样约束解决方式；阶段胜利会产生什么更难处理的后果；读者最初得到的承诺最终有哪些可行兑现方向。

## 一卷的展开层次

起始局面 → 主角的可执行目标 → 第一策略及阻碍 → 由行动引出的新证据或新代价 → 关系中的选择 → 阶段结果 → 下一阶段问题。写事件之间的联系，不把这几个标题换词当成内容。

## 商场经营示例（虚构）

薄弱写法：“主角在商场创业，遭遇竞争，克服困难并获得成长。”

可展开的局面：主角接手母亲留下的修鞋摊，租约将在月底到期。他想靠周年活动的客流补足欠租，但活动方要求摊位提供统一收款记录。主角曾替邻摊代收现金，账上流水无法直接说明真实营业额。隔壁店主愿意作证，却要求主角撤回对其占用过道的投诉。主角选择提交原始记账本，自己的违规代收也因此暴露。阶段结果可以是获得短期续租但接受整改，下一卷面对整改成本与邻摊关系，而不是突然收购整个商场。

此例用于展示利益、证据与选择，不作为现实商场制度或法律事实。

## 质量复核

每卷是否有可辨认的起点和终点；核心转折是否改变人物能做的事；关键配角是否作出自己的决定；伏笔是否能指出对应的铺垫；卷末后果是否承接下一卷。若换掉人物姓名便能套入任何小说，仍需补充本书特有的资源、关系与规则。
