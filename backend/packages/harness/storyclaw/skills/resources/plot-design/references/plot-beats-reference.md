# 情节线、伏笔与重复事件

## 区分三种东西

事实：正文中已发生且有来源的事件。
计划：作者准备将来安排的事件，尚未兑现。
伏笔：已经投放到正文、引起合理期待但仍未解释或兑现的细节。只有作者笔记中的秘密，还不是读者已见的伏笔。

沿用现有情节线或伏笔 ID。新建议先写候选名称、计划作用与前置条件，不编造持久 ID 或声称已经更新状态。

## 生命周期工作单

记录起始来源、当前解释、相关人物的知情范围、最近一次推进、兑现所需条件、可能兑现的阶段及改变计划的理由。暂缓不等于遗漏；尚未出现承诺或期限时，不把没有回收判作硬伤。回收后还可能产生追责、失望或关系变化，这些是后果线，不是重复回收。

## 多线取舍

本章主目标解决什么问题；支线怎样改变主目标的资源、决定或风险；当前不推进的线是否仍有读者期待需要维持。支线长期不动时，提出推进、合并、延后或删除未来安排的选择，不擅自修改已发生事件。

## 语义重复检查

比较主体、对象、意图、关键动作、结果、角色认知，而不是只比句子。若第十章已付款拿到货，第十一章换一套措辞再次付款拿货，属于状态重置；若第十一章追问货物有无缺陷、要求退货，则是新事件。必要回顾只需提供理解当前行动所需的信息。

## 反转与回收的证据

揭露前至少存在可回看的观察、矛盾或行动后果。允许人物误解，允许读者暂时不知道解释；不能用揭露时首次出现的万能规则同时解释所有疑点。对既有正文的诊断同时引用铺垫与兑现片段；缺其中一端时写“需核对”，不假报确定矛盾。
