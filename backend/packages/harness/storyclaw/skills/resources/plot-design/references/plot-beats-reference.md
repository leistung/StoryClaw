# 情节节点设计参考

## 输出 JSON 结构

```json
{
  "chapters": [
    {
      "number": 1,
      "beats": [
        {"name": "开端", "content": "30-80字描述该节点"},
        {"name": "伏笔", "content": "埋下后续回收线索"}
      ],
      "main_line": "本章主线推进描述",
      "sub_lines": ["支线1推进描述", "支线2推进描述"]
    }
  ],
  "foreshadowing": [
    {
      "id": "f1",
      "planted_at": 1,
      "resolved_at": 3,
      "description": "伏笔内容与回收规划"
    }
  ]
}
```

## 节奏节点类型

| 节点 | 作用 | 出现位置 |
|------|------|---------|
| 开端 | 介绍场景/引入冲突 | 章首 |
| 发展 | 推进主线/深化矛盾 | 章中前段 |
| 转折 | 反转/新信息/视角切换 | 章中后段 |
| 高潮 | 冲突爆发/情感顶点 | 章尾前 |
| 收束 | 悬念/留白/过渡 | 章尾 |
| 伏笔 | 埋设后续线索 | 任意位置 |
| 回收 | 呼应前文伏笔 | 需与 planted_at 对应 |

## 节奏原则

1. **张弛有度**：不连续两章都是高潮，高潮后需有缓冲
2. **主线推进**：每章主线必须有增量，不能原地踏步
3. **支线穿插**：支线不宜超过 2 条/章，避免分散焦点
4. **伏笔回收**：所有伏笔必须有 resolved_at 规划，不悬空

## 常见节奏问题

| 问题 | 表现 | 修复 |
|------|------|------|
| 平铺直叙 | 全章无转折，信息匀速 | 在章中后段插入反转 |
| 转折过密 | 一章 3+ 转折，读者疲劳 | 拆分到相邻章 |
| 支线喧宾夺主 | 支线占比超过主线 | 压缩支线或移到下章 |
| 伏笔悬空 | planted_at 无对应 resolved_at | 补充回收规划 |
