# 人物档案和弧光工作单

按当前任务取用，不要求每次都填写全部项目；下面是内容维度，不是固定接口。

## 新建或扩写档案

- 身份：姓名、别名、角色位置与当前处境，已确认信息和暂定建议分开。
- 目标：长期追求与当下迫切目标，二者冲突时如何选择。
- 底线：不愿付出的代价；什么压力可能逼其试探底线。
- 资源：能力、关系、物品、地位与限制；不能只有优势没有失效条件。
- 关系：双方诉求、历史债务、误解、信任与依赖，不只列“朋友/仇敌”。
- 知情：亲历什么、听谁说过什么、误信什么、正在隐瞒什么。
- 表现：一个能呈现上述矛盾的候选场景及一小段符合声音的对白。
- 发展：可能的转变方向与触发条件，保持为未来建议。

## 弧光报告

先注明分析的正文范围及缺失资料。用来源支持初始状态；逐个关键事件说明压力、人物选择、即时收益、付出代价、后来如何调整行为。未来部分写分支条件，不给未提供的精确章号，也不把候选对白伪装成原文。

## 三种可选走向

成长：原办法失效后学会承担或合作，但保留原有长处。
堕落：为了短期收益逐步让渡底线，收益和后果都可追踪。
坚守：面对不同诱惑持续作出同类价值选择，因此改变关系或局面。

不是每个人都要完成其中一种标准弧线。角色可以停滞、反复、在一个维度改变而在另一个维度保持。

## 完整性检查

角色是否有无需主角批准的行动？关键转变有没有触发和过渡？其知道的信息是否有来源？同一关系的两端是否都能解释行为？档案中的能力是否足够支撑拟写场景，而非到了高潮才补一项万能特长？
