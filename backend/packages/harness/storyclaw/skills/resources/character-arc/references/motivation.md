# 动机怎样落到行动

## 四个问题

此刻要得到什么？为什么现在必须做？最怕损失什么？愿意付到哪一步？答案互相冲突时才会产生有意义的选择。“想成功”不足以安排场景，“想在妹妹回家前补齐押金，又不肯让她知道摊位亏损”才有行动方向。

## 外在愿望与内在需要

愿望可以是赢得诉讼、找回家人、守住店面、获得认可；内在需要可能是接受帮助、承认误判，也可能是坚持原先正确的价值。需要是创作分析，不应由叙述者直接宣布。静态人物可以通过坚持改变周围人，不一定自己经历性格反转。

## 关系是双向的

主角向师傅求技术，师傅希望有人继承手艺，但不愿交出客源；同伴愿意作证，却要求主角承担先前隐瞒的后果。为每个人保留独立诉求，避免“因为是配角所以无条件奉献”。对立也可来自善意目标的冲突，不必人人恶意。

## 声音的具体差异

比较人物如何组织请求、是否先讲事实、如何称呼别人、遇到不确定时是否承认、会省略哪些双方知道的信息。受教育程度、经历和场合共同影响表达，不能机械对应粗口、文言或长句。紧急时说短句并不自动改变其人格。

## 行动压测

如果人物必须使用尚不知道的信息，先安排合法的信息获得路径；如果只为了给主角让路而放弃自身利益，补充更强的诉求、约束或关系依据；如果一个标签能解释相反的所有行为，改用特定处境下的选择证据。

示例：角色原先“从不求人”，后来向对手借钱，不必立即判定崩人设。先看亲人的治疗期限、替代办法是否已耗尽、他愿意承担何种条件，以及事后是否仍保留原来的自尊与防备。
