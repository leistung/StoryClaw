# character-arc

## Description

生成人物档案、动机关系与成长或堕落弧线，解释人物为何这样选择、怎样付出代价；也用于审查人设变化是否有铺垫。

## Parameters

读取题材、人物定位、现有姓名与别名、已写行为、关系、能力边界和计划中的阶段目标。分清新建角色、扩写档案、未来弧光建议和已有表现分析。

## Method

1. 建立身份锚点：姓名与别名、当下角色、生活处境、在故事中的资源和依赖。已有身份、年龄、生死、亲属关系和出场经历保持不变；未提供的要区分暂定建议。
2. 从欲望、需要、恐惧和价值底线推导行动。欲望是角色主动追求的东西，需要是其尚未意识到的改变，恐惧说明为何不走看似容易的路；不强行让每个角色都有创伤。
3. 设计能力与短板的实际作用：擅长什么、解决到哪一步会失效、需要谁帮助、失败会损失什么。用具体决策表现聪明，不靠旁白夸奖或配角失智证明。
4. 用关系中的利益和历史塑造人物。对每条关键关系写双方各自想得到什么、误解什么、依赖什么以及底线；配角和对手要有离开主角也成立的生活与目标。
5. 记录信息边界：人物亲历、被告知、推测、误信或刻意隐瞒的内容。作者知道的秘密不能自动成为人物的决策理由，人物说法也不能直接提升为客观事实。
6. 按事件设计弧线：原有应对方式 → 遭遇使其失效的压力 → 试图维持旧方式 → 作出代价更高的新选择 → 结果及残留问题。允许反复、静态坚守和悲剧，不把成长写成属性直线上升。
7. 给人物可复用的声音与行为特征：如何拒绝、求助、掩饰紧张、面对权威和亲近者；特征随场景变化，不把口头禅塞进每句对白。
8. 档案覆盖按确认数量和角色功能安排。扩写每个档案时加入可以进入场景的选择、矛盾与关系，而不是反复堆“冷静、善良、坚毅”标签。

## Constraints

- 分析既有角色需引用行为证据；变化本身不等于崩人设，先检查诱因、时间和视角。
- 新人物关系、重大隐情与命运都是候选，不能声称已经加入正史。
- 不因题材强加恋爱、复仇、悲惨童年或黑化；不把性别、职业或身份当作固定性格。
- 作者明确只改一个档案时，不顺带重构其他人物或改写已写情节。
- 此 Skill 提供创作方法；保存、采用、计费、发布和数据访问权限由调用能力决定。输出服从调用方 schema，不把方法示例变成新接口。

## Output

人物档案应能支持写作者安排其下一次具体行动；弧光报告区分已发生表现和未来方案，说明触发事件、选择、代价及关系后果。若接口只给 name/category/description，将细节组织进 description，不另造字段。
