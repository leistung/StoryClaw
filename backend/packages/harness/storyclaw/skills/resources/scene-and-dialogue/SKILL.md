# scene-and-dialogue

## Description

增强已有场景的空间、氛围与行动可读性，或打磨对白的角色声音、交锋与潜台词；保持原有事实、信息和修改范围。

## Parameters

读取所选文本、场景上下文、参与人物及关系、视角、作者希望改变的效果。先区分场景增强与对白打磨，不在局部表达任务中重构整段剧情。

## Method

1. 确认场景此刻在发生什么，人物想得到什么，读者需要看清哪种变化。增强表达必须服务行动、关系或情绪，不能只是增加装饰段落。
2. 场景增强先核对空间：人物相对位置、出入口、视线与声源、可触物品、动作顺序。再选择视角人物会注意的光、声、触感等少量细节，不要求五感齐全。
3. 让环境参与动作：噪声迫使人物靠近说话，柜台遮住手部动作，雨水改变行走速度。若新增环境会改变证据、逃离路径或信息可达性，就可能是剧情修改，需要已有依据或作者授权。
4. 对白打磨先辨认每个发言者的即时诉求、对受众的判断、愿意承认与不愿公开的内容。潜台词来自目标冲突，不等于所有人都说谜语。
5. 让回应发生变化：追问、转移、让步、试探、拒绝、沉默均需影响后续。删掉重复解释的轮次，保留理解事件必需的信息和对方实际听到的内容。
6. 通过称谓、句式、语汇、停顿与具体经验区分声音；随关系和压力变化，避免以固定口头禅、粗口或方言刻板代表职业与身份。
7. 用必要动作让读者辨认说话者和压力，不在每句对白后附加皱眉、冷笑、握拳。内心与外在表达可以不一致，但有限视角只能确定自己能观察或知道的部分。
8. 放回上下文检查：新描写有没有改变位置、天色或天气；对白是否改变承诺、告知对象或秘密揭示；场景结束时是否保持作者原定事实结果。

## Constraints

- 不用新增门、暗道、目击者、关键声响等决定性条件伪装成单纯画面增强。
- 不把含混、推测或试探改成确定承认，不为了戏剧性让角色全知。
- 不强迫对白都短促或都有潜台词；明确说明在有些场合更符合人物目标。
- 输出仅覆盖请求范围；调用方已经区分 scene/dialogue 模式时遵循该模式。
- 此 Skill 提供创作方法；保存、采用、计费、发布和数据访问权限由调用能力决定。输出服从调用方 schema，不把方法示例变成新接口。

## Output

交付可替换的场景或对白候选，保留说话者可辨识、段落清楚、事实与信息流一致。除非调用方要分析，不附解释、评分、表格或改写过程。
